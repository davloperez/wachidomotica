# wachidomotica

Configuración domótica de Villawachitos. Pensado para abrirse con **VSCode** en la raíz del repositorio
(acepta las extensiones recomendadas; las tareas están en _Terminal → Ejecutar tarea_).

| Carpeta | Contenido |
| --- | --- |
| [`villawachitos/esphome`](villawachitos/esphome) | Firmware ESPHome de los dispositivos (tareas _ESPHome: …_) |
| [`villawachitos/dashboards/functional-v2`](villawachitos/dashboards/functional-v2) | Panel de pared ligero para pantallas pequeñas y verticales: plano 2D, vista general de la casa y detalle de cada estancia. Se publica como «Casa General» y en los paneles Shelly, cada uno con su estancia por defecto (tareas _Functional v2: …_) |
| [`villawachitos/dashboards/shared`](villawachitos/dashboards/shared) | Script de deploy y comprobación comunes; `.env` compartido en `villawachitos/dashboards/.env` |
